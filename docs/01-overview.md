# 01. Обзор проекта

## Что это

Проект решает одну задачу: **построить сильный AI для тоғызқұмалақ** — традиционной
казахской игры семейства манкала. Вокруг этой задачи выросла исследовательская
инфраструктура: движок, генерация данных, обучение нейросетей, анализ партий
живых игроков и два веб-интерфейса.

Проект исследовательский, а не продуктовый. Один компонент (Rust-движок) доведён
до рабочего состояния и задеплоен, остальное — эксперименты разной степени
завершённости, многие из которых по отчётам оказались неудачными.

## Два трека AI

Проект содержит две независимые реализации игрового AI, которые **не связаны
между собой** и даже используют разные реализации правил игры.

### Трек 1 — Rust alpha-beta + NNUE (основной)

Классический подход из компьютерных шахмат: alpha-beta поиск с большим набором
отсечений плюс быстрая нейросетевая оценка позиции (NNUE). Это рабочий,
задеплоенный движок. Оценка силы по отчётам — примерно **+926 Elo** над
базовой ручной оценкой.

```
Позиция → [дебютная книга] → [EGTB] → alpha-beta поиск → NNUE/HCE оценка → ход
```

### Трек 2 — AlphaZero (эксперимент)

Свёрточная ResNet с policy- и value-головами, MCTS под управлением сети,
самообучение. По [FULL_REPORT.md](../FULL_REPORT.md) прироста силы относительно
NNUE-движка не дал. Код сохранён, обученных весов в репозитории нет.

## Технологический стек

| Компонент | Технология | Зависимости |
|-----------|-----------|-------------|
| Движок | Rust 2021, opt-level 3, LTO | **нет** |
| Обучение NNUE | Python + PyTorch | torch, numpy |
| AlphaZero | Python + PyTorch + ONNX | torch, onnx, tensorboard |
| Веб-сервер | Python + Flask | flask |
| Фронтенд `web/` | Vanilla JS, один HTML-файл | нет |
| Фронтенд `alphazero-code/` | Vanilla JS + Web Workers | onnxruntime-web (CDN) |

Отсутствие зависимостей у движка — сознательное решение: [`Cargo.toml`](../engine/Cargo.toml)
содержит пустую секцию `[dependencies]`. Хэширование, потокобезопасная таблица
транспозиций, генератор псевдослучайных чисел, инференс нейросети — всё написано
вручную.
