# 02. Правила игры и их реализация

Раздел описывает правила тоғызқұмалақ в том виде, в каком они закодированы в
[`engine/src/board.rs`](../engine/src/board.rs). Официальные правила лежат в
репозитории отдельным PDF:
[Правила игры «Тоғызқұмалақ» (казахстанская версия)](<../alphazero-code/Правила игры «Тоғызқұмалақ» (казахстанская версия).pdf>).

## Доска

Две стороны по 9 лунок (**отау**), в каждой изначально 9 камней (**құмалақ**).
Всего на доске 162 камня. У каждого игрока есть накопитель — **қазан**.

```
Чёрные:   [9] [9] [9] [9] [9] [9] [9] [9] [9]     қазан: 0
           9   8   7   6   5   4   3   2   1

Белые:     1   2   3   4   5   6   7   8   9
          [9] [9] [9] [9] [9] [9] [9] [9] [9]     қазан: 0
```

Внутреннее представление ([`board.rs:52-59`](../engine/src/board.rs#L52-L59)):

```rust
pub struct Board {
    pub pits: [[u8; 9]; 2],   // [сторона][лунка], индексы 0..8
    pub kazan: [u8; 2],       // накопленные камни
    pub tuzdyk: [i8; 2],      // позиция тұздық, -1 = нет
    pub side_to_move: Side,   // White = 0, Black = 1
    pub move_count: u16,
}
```

Структура занимает 24 байта и реализует `Copy` — это позволяет поиску
использовать стратегию copy-make вместо make/unmake.

Нумерация лунок в коде — 0..8, в интерфейсе и выводе — 1..9.

## Ход

Игрок выбирает свою непустую лунку и раздаёт из неё все камни против часовой
стрелки. Правило раздачи имеет особый случай, который легко упустить
([`board.rs:141-180`](../engine/src/board.rs#L141-L180)):

**Если камней больше одного** — первый камень возвращается в исходную лунку,
остальные раздаются по одному в следующие:

```rust
self.pits[current_side][current_pit] += 1;  // первый камень — обратно
let mut remaining = stones - 1;
```

**Если камень ровно один** — он переходит в следующую лунку, исходная остаётся
пустой.

Раздача идёт по своей стороне слева направо, затем переходит на сторону
соперника и продолжается по кругу.

## Захват

Если последний камень попал в лунку **на стороне соперника** и количество камней
в ней стало **чётным** — все камни из этой лунки уходят в қазан ходившего
([`board.rs:194-198`](../engine/src/board.rs#L194-L198)).

Захват на своей стороне невозможен.

## Тұздық

**Тұздық** («солёная лунка») — ключевой механизм игры. Если последний камень
попал в лунку соперника и в ней стало **ровно 3 камня**, эта лунка объявляется
тұздық: она переходит в собственность ходившего, эти 3 камня забираются, и
дальше **всё, что в неё попадает, автоматически идёт в қазан владельца**.

Условия создания ([`can_create_tuzdyk`, board.rs:223-238](../engine/src/board.rs#L223-L238)):

| Ограничение | Код |
|-------------|-----|
| У игрока ещё нет тұздық (он один за партию) | `if self.tuzdyk[player] != -1 { return false }` |
| Нельзя объявить 9-ю лунку | `if pit_index == 8 { return false }` |
| Нельзя объявить лунку, симметричную тұздық соперника | `if self.tuzdyk[opponent] == pit_index { return false }` |

Обработка попадания камня в тұздық ([`board.rs:170-176`](../engine/src/board.rs#L170-L176)):

```rust
if current_side == opp && self.tuzdyk[me] == current_pit as i8 {
    self.kazan[me] += 1;              // мой тұздық на стороне соперника
} else if current_side == me && self.tuzdyk[opp] == current_pit as i8 {
    self.kazan[opp] += 1;             // тұздық соперника на моей стороне
} else {
    self.pits[current_side][current_pit] += 1;
}
```

Тұздық также **блокирует ход**: игрок не может ходить из лунки, объявленной
тұздық соперника ([`valid_moves_array`, board.rs:91-104](../engine/src/board.rs#L91-L104)).

## Завершение партии

Условия ([`game_result`](../engine/src/board.rs)):

1. **82+ камня в қазане** — немедленная победа (`WIN_THRESHOLD = 82`, больше
   половины от 162).
2. **Атсыз қалу: у стороны, которая должна ходить, нет камней.** Партия
   заканчивается, а все камни, оставшиеся на доске, получает тот, на чьей
   стороне они лежат, — то есть соперник забирает всё со своей стороны в свой
   қазан. После этого сравниваются итоговые суммы.
3. **81:81** — ничья.

```rust
let me = self.side_to_move.index();
if self.pits[me].iter().all(|&x| x == 0) {
    let my_total  = kazan[me];
    let opp_total = kazan[opp] + sum(pits[opp]);   // остаток — владельцу стороны
    /* сравнение my_total и opp_total */
}
```

Важно: пустая сторона **у того, кто только что сходил**, партию не завершает —
соперник ходит, и его раздача может снова дать камни на пустую сторону.

> **Историческая справка.** До исправления движок завершал партию, как только
> пустела *любая* сторона, и сравнивал только қазаны, без остатка на доске.
> Из-за этого движок считал выигрышем «опустошить свою сторону, будучи впереди
> по қазану», хотя по правилам все оставшиеся камни уходят сопернику. Это прямо
> совпадает с замечанием сильных игроков, что движок «не бережёт камни» в
> эндшпиле. Веб-интерфейс ([`web/index.html`](../web/index.html), `getGameResult`)
> уже использовал правильное правило, так что движок и арбитр расходились.
> EGTB, собранные по старому правилу, больше не загружаются (формат `TKEGTB02`),
> их нужно перегенерировать командой `egtb-gen`. Обучающие данные NNUE,
> сгенерированные до исправления, содержат результаты партий по старому правилу.

Истощение соперника (starvation) остаётся самостоятельной стратегией: если
соперник не может сходить, вы забираете в қазан все камни со своей стороны.
Но теперь движок видит и обратную сторону — собственные камни на доске
ценны, отдавать их ради «досрочного» конца партии нельзя.

## Формат позиции

Движок принимает позицию строкой из пяти секций, разделённых `/`
([`parse_position`, main.rs:628](../engine/src/main.rs#L628)):

```
w0,w1,...,w8 / b0,b1,...,b8 / kw,kb / tw,tb / side
```

| Секция | Смысл |
|--------|-------|
| `w0..w8` | камни в лунках белых |
| `b0..b8` | камни в лунках чёрных |
| `kw,kb` | қазаны белых и чёрных |
| `tw,tb` | позиции тұздық (`-1` — нет) |
| `side` | чей ход: `0` — белые, `1` — чёрные |

Начальная позиция:

```
9,9,9,9,9,9,9,9,9/9,9,9,9,9,9,9,9,9/0,0/-1,-1/0
```

## Три реализации правил

Правила написаны в проекте **трижды**, независимо друг от друга:

| Реализация | Файл | Использование |
|------------|------|---------------|
| Rust | [`engine/src/board.rs`](../engine/src/board.rs) | движок, EGTB, datagen |
| Python | [`alphazero-code/alphazero/game.py`](../alphazero-code/alphazero/game.py) | обучение AlphaZero |
| JavaScript | [`alphazero-code/game.js`](../alphazero-code/game.js) | браузерный AI |

Автоматической кросс-проверки между ними нет. [`validate_perft.py`](../validate_perft.py)
проверяет только Rust-версию. Риск расхождения описан в
[13-known-issues.md](13-known-issues.md#3-правила-игры-реализованы-трижды).
