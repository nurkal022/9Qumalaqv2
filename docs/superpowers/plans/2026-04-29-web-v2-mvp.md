# web-v2 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `web-v2/` MVP per [the design](../specs/2026-04-29-web-v2-mvp-design.md) — Svelte/Vite/Tailwind frontend + FastAPI/SQLite/JWT backend with WebSocket eval streaming, anonymous + optional account auth, full play loop against the NNUE engine, and persistent game history. Mobile-first, dark Kazakh-themed design.

**Architecture:** Two parallel apps under `web-v2/{backend,frontend}`. Backend wraps the existing `engine/target/release/togyzkumalaq-engine` binary as a subprocess (`serve` mode), serializes engine access with `asyncio.Lock`, and streams `info` lines to WebSocket subscribers. Frontend is a Svelte 5 SPA with hash routing, REST + WebSocket client, and Tailwind-driven design system.

**Tech Stack:** FastAPI 0.115+, SQLAlchemy 2.x async, aiosqlite, Alembic, bcrypt, PyJWT, slowapi, pytest + httpx; Svelte 5, Vite 5, TypeScript 5, TailwindCSS 4, svelte-spa-router, vitest.

---

## Milestones

1. **Foundation** (Tasks 1-3): Both apps boot. Backend `/health` reachable from frontend.
2. **Database + Anonymous auth** (Tasks 4-6): SQLite with users/games/moves migration; anonymous session cookie + `/api/auth/me`.
3. **Account auth** (Tasks 7-9): Register + login + logout + JWT cookie + games migration; frontend Auth UI.
4. **Engine integration** (Tasks 10-12): Engine pool subprocess + lock + stream subscribers; WebSocket handler.
5. **First playable game** (Tasks 13-16): `POST /api/play/new`, `POST /api/play/{id}/move`, Board + Lobby + Game pages, EvalBar driven by WS.
6. **Game features** (Task 17): Undo, takeback, resign, draw_offer, hint endpoints + frontend controls.
7. **History** (Tasks 18-19): List + get endpoints, History + GameView pages.
8. **Polish** (Tasks 20-21): Global error handling + toasts, rate limits, ornaments, README.

After every task: `pytest -q` (backend) + `npm run check` + `npm run test` (frontend) all green.

```python
"""FastAPI application factory."""
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

from app.config import settings


def create_app() -> FastAPI:
    app = FastAPI(title="Togyzkumalak web-v2 API", version="0.1.0")

    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.cors_origins,
        allow_credentials=True,
        allow_methods=["*"],
        allow_headers=["*"],
    )

    @app.get("/health")
    async def health() -> dict[str, str]:
        return {"status": "ok"}

    return app


app = create_app()
```
